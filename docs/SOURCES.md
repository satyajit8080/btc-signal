# Source-to-metric mapping

Generated by `python scripts/gen_sources_doc.py` from `app/providers/catalog.py`. Do not edit by hand.

Relevance is the default `source_relevance_score`; `0` means the source can never move the BTC score.
Reliability starts at the listed base and is scaled live by each adapter's recent success rate.

Access: **free** = official public API, no key · **key**/**paid** = configurable via env · **no_api** = nothing to integrate legally/technically · **blocked** = public page refuses automation.
